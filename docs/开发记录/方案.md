## 一、一句话目标

做一个只给自己用的 Mac 菜单栏小软件，把截图、贴图、录屏、剪贴板历史这些常用小工具装进一个"工具箱"，按一个快捷键就能用，不用再装一堆软件。

## 二、你的电脑现在是什么情况（我查过了）

| 项目 | 情况 | 说明 |
|---|---|---|
| 系统 | macOS 15（Sequoia），Apple 芯片 | 支持苹果最新的截图/录屏接口（ScreenCaptureKit），录屏可以直接写成 mp4 |
| Swift 编译器 | 6.2.3（命令行工具自带） | 能编译，但没装 Xcode |
| Xcode | 没装 | 见第六节 |
| 磁盘 | 空间够 | 装 Xcode 没问题 |
| 已装的同类软件 | Snipaste、QQ | 你习惯的快捷键和操作可以照搬 |

## 五、技术方案（人话版）

- 用苹果自家的 Swift 语言写原生 App，住在菜单栏（顶部一个小图标），不占 Dock。
  原因：截图/录屏/剪贴板都要调系统底层接口，原生最快最稳最省电；上面调研的开源项目几乎全是 Swift，可以直接学。
- 每个功能是一块独立的"积木"（模块），工具箱是个架子。想加新工具就加一块积木，一块坏了不影响别的。
- 用苹果自带的能力，不自己造轮子：

| 功能 | 苹果自带能力 | 要什么权限 |
|---|---|---|
| 截图、录屏 | ScreenCaptureKit（macOS 15 能直接录成 mp4） | 屏幕录制权限，首次授权一次 |
| 系统声音 | ScreenCaptureKit 自带音频 | 同上 |
| 麦克风 | AVFoundation | 麦克风权限 |
| 剪贴板历史 | NSPasteboard（每半秒看一眼有没有新内容，Maccy 也这么做） | 不用 |
| OCR | Vision（支持中文） | 不用 |
| 取色 | NSColorSampler | 不用 |
| 全局快捷键 | Carbon RegisterEventHotKey | 不用（不需要辅助功能权限） |
| 窗口吸附（可选） | Accessibility API | 辅助功能权限 |

- 数据全在本地，不联网，不上传。

## 六、开发工具（10-28 更新：原计划变了）

原计划是从 App Store 装 Xcode，但查下来装不上：

| Xcode 版本 | 要求的系统 | 你的电脑（macOS 15） |
|---|---|---|
| Xcode 27（App Store 现在给的） | macOS 26.6 以上 | 装不上 |
| Xcode 26.4 及以后 | macOS 26.2 以上 | 装不上 |
| Xcode 26.0 到 26.3 | macOS 15.6 以上 | 能装，但 App Store 不给，要去苹果开发者网站用 Apple ID 登录下载 |

所以现在改成：先不用 Xcode。电脑自带的命令行工具（Swift 6.2.3）已经能编出完整的 App，台阶 0+1 就是这样编出来的，见第十一节。

命令行方式只有一个小麻烦。现在用的是"临时签名"，每编一个新版本，系统就会认不出它，要重新给一次"录屏与系统录音"权限。解决办法是在钥匙串里建一个只给 MacKit 用的"本机签名证书"，建好以后新版本也能一直用同一个权限。这一步要你点头才做。

要不要再装 Xcode，原先给了三条路：A 不装、B 装 Xcode 26.3、C 升级系统装 Xcode 27。

10-28 你选了 B：装 Xcode 26.3。它是 macOS 15 上能装的最后一个版本，要求 macOS 15.6 以上，你的系统可以装。

装好以后的变化：

- 编译脚本会自动改用 Xcode 编译，没装时继续用命令行，产物都在 build/MacKit.app
- 你登录 Apple ID 后，MacKit 改用你的 Apple Development 证书签名。以后出新版本，录屏权限不会再丢
- 能用 Xcode 打开 MacKit.xcodeproj 断点调试。这个工程由 project.yml 生成，改设置要改 project.yml
- 你的团队编号只写在 Config/Local.xcconfig 里，这个文件不进 git

### 装 Xcode 26.3 的步骤（要你来做）

1. 打开苹果的下载页，用 Apple ID 登录。免费账号就行，不用付费开发者会员：https://developer.apple.com/download/all/?q=Xcode%2026.3
2. 找到 Xcode 26.3，下载 Xcode_26.3_Apple_silicon.xip。不要选 Universal 版，那个更大
3. 下载完，在"下载"文件夹里双击这个 .xip。系统会解压出 Xcode.app，要等几分钟到十几分钟
4. 把 Xcode.app 拖进"应用程序"文件夹
5. 打开终端，依次运行下面三条命令。它们会要你输开机密码：

```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
sudo xcodebuild -license accept
sudo xcodebuild -runFirstLaunch
```

6. 打开一次 Xcode。如果它问要下载哪些平台，比如 iOS、watchOS，都不用勾，直接继续。做 Mac 软件不需要它们
7. 在 Xcode 菜单里打开设置，进 Accounts，点左下角的加号，选 Apple ID 登录
8. 选中你账号下的 Personal Team，点 Manage Certificates，再点左下角的加号，选 Apple Development
9. 回来告诉我"装好了"。剩下的我来做：填团队编号、用 Xcode 编译、跑全部检查、重新安装

10-28 已全部完成。中途遇到过一个情况：开发证书由苹果 G3 中间证书签发，一开始钥匙串里只有 2023 年过期的旧版，证书显示无效。G3 补上后就正常了。以后在别的 Mac 上遇到"0 valid identities"，先查这个。

## 十一、台阶 0 + 1 做了什么

做完后你能干什么：

- 菜单栏右上角有个扳手图标，点开是 MacKit 的菜单，能退出
- 按 ⌘1，屏幕"冻住"变暗，鼠标移到哪个窗口，哪个窗口就亮起来并显示像素尺寸
- 拖动鼠标框选一块；或者单击一个窗口截整个窗口；在桌面空白处单击截整块屏幕
- 松手后自动复制到剪贴板，同时存成 PNG，屏幕下方提示"已复制到剪贴板，已保存"
- Esc 或右键取消；回车确认当前高亮的框
- 菜单里能换快捷键（⌘1 / ⇧⌘1 / F1 / ⌃⌥A）、改保存位置、关掉存文件、截整个屏幕
- 多块屏幕、Retina 屏都支持，截出来是原始清晰度

## 十二、台阶 0 + 1 验收清单

已经换成正式签名，现在就可以验收。录屏权限给一次，以后出新版本也会一直保留。

0. 只在第一次需要：清掉系统里 MacKit 的旧权限记录（见下面"10-28 第一次验收卡住"）

```bash
tccutil reset ScreenCapture local.mackit.MacKit
```

1. 退出 Snipaste：点菜单栏的 Snipaste 图标，选退出
2. 启动 MacKit：在终端运行 `open ~/Applications/MacKit.app`
3. 看菜单栏右上角有没有扳手图标。刘海屏图标多的话，它可能被刘海挡住；看不到也没关系，快捷键照样能用
4. 按 ⌘1。第一次会弹出系统的授权窗口：点"打开系统设置"，打开 MacKit 的开关，系统问"退出并重新打开"时点它
5. 系统可能还会问 MacKit 能不能"绕过系统的私密窗口选择器"直接录屏，选允许。macOS 15 大约每个月会再问一次
6. 再按 ⌘1，拖一块区域，松手
7. 到微信或 QQ 的聊天框按 ⌘V，图片能发出去 = 台阶 1 通过
8. 顺便试试：单击窗口截整窗、桌面上单击截整屏、Esc 取消、菜单里"截图保存位置 → 在访达中打开"能看到 PNG
9. 菜单里点"退出 MacKit"能退出 = 台阶 0 通过

不对劲的话，把看到的现象告诉我。我能用下面的命令看 MacKit 自己记的日志。要写完整路径，因为在 zsh 里 log 是另一个同名命令：

```bash
/usr/bin/log show --last 10m --predicate 'subsystem == "local.mackit"'
```

### 10-28 第一次验收卡住

现象：按 ⌘1 一直弹"需要录屏与系统录音权限"，在系统设置里开了也没用，多按几次还会叠出好几个提示框。

原因：系统里早就存了一条 MacKit 的权限记录，是给换正式签名之前的旧版记的。系统日志里反复出现 "Failed to match existing code requirement"，意思是记录和现在的签名对不上，所以开关怎么拨都不算数。

处理：
- 用户这边：运行上面第 0 步的命令，只清掉 MacKit 自己的记录，再重新授权一次。以后都用同一张证书签名，不会再出现
- 代码这边：提示框只弹一个；权限判断改成"先真的截一次，失败才提示"；提示框里加了"开了还不行就点 − 删掉重来"；关键日志改成会存到磁盘的级别
