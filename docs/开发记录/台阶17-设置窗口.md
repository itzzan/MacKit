## 现在的样子

- 设置散在菜单里：截图设置、录屏设置、剪贴板设置、识别设置，各是一个子菜单
- 快捷键只能从几套里挑（比如截图只有 ⌘1 / ⇧⌘1 / F1 / ⌃⌥A），撞了别的软件也没法自己定

- "看看有没有新版本"只是打开 GitHub 的网页，要自己比版本号

## 做完后你能干什么

### 一个正经的设置窗口

- MacKit 菜单最下面"设置…"（菜单开着时按 ⌘,）打开；上面一排图标分页：
  - **通用**：开机自动启动；检查更新；四种权限（屏幕录制、辅助功能、麦克风、摄像头）各自开没开、没开的"去打开"；再看一次欢迎窗口
  - **快捷键**：截图、贴图、显示 / 隐藏贴图、剪贴板、录屏、识别文字、测量、屏幕画笔，全在一张表里
  - **截图**：存不存文件、保存位置、快速模式、取色复制成 HEX 还是 RGB
  - **录屏**：画质、保存位置、录完打开预览
  - **剪贴板**：暂停记录、不记录的软件、清空历史、自动粘贴的权限
- 改了马上生效，不用重开 MacKit

### 快捷键随便按

- 点一个快捷键，写着"按下新的快捷键…"，你按什么组合就是什么；Esc 不改了；⌫ 清掉（这个功能不要快捷键）
- 设之前帮你查：
  - 和 MacKit 自己别的快捷键撞了：不让设，说明撞了哪个
  - 只有字母、数字、没带 ⌘ ⌃ ⌥（比如单按 A、⇧A）：不让设，不然你打字时会被截走
  - 系统自己用的（⇧⌘3、⇧⌘4、⇧⌘5 截图，⌘Space Spotlight 等）：提醒，让你换一个
  - 和别的软件撞了：系统不告诉 MacKit，只能提醒你"按了没反应就换一个"
- 每一行后面有"恢复默认"；表下面有两个"一键套用"：⌘1–⌘6 那套、⌃⇧1–⌃⇧6 那套（看第 2 条拍板）
- 紧急退出 ⌃⌥⌘Q 固定不能改（卡住时救命用）

### 开机自动启动

- 通用页里勾一下（看第 3 条拍板）；系统会在"系统设置 → 通用 → 登录项"里列出 MacKit，那边也能关
- 系统要你点同意的话，旁边会有"去系统设置里同意"

### 检查更新

- 通用页、菜单"关于 MacKit"里都有"检查更新"：点了问一下 GitHub 最新发布的版本
- 已是最新：写"已是最新版本 1.5.1"
- 有新的：写新版本号和更新说明，"去下载"打开发布页（不自动下载安装）
- 连不上：写"连不上 GitHub，等会儿再试"
- 只有点的那一下联网；只问版本号，不发任何你的东西

## 怎么验收

1. 菜单最下面"设置…"打开设置窗口，五页都能点开；菜单里原来的"截图设置""录屏设置"这些子菜单没了
2. 快捷键页：把截图改成 ⌃⌥S，关掉窗口按 ⌃⌥S：开始截图；原来的 ⌘1 不再截图
3. 试着把录屏也设成 ⌃⌥S：不让设，说和截图撞了；试着设成单按 S：不让设
4. 点"恢复默认"：截图变回原来的；点"一键套用 ⌘1–⌘6"：全回到你现在用的这套
5. 勾上"开机自动启动"：系统设置的登录项里有 MacKit；取消勾：没了
6. 点"检查更新"：写着"已是最新版本"（GitHub 上现在最新是 1.0.0，你这台是 1.5.1）
7. 截图页改保存位置、录屏页改画质、剪贴板页勾"暂停记录"：都马上生效，和以前在菜单里改的一样

## 技术要点（备忘）

- 设置窗口：普通窗口，上面一排图标分页（系统自带的"偏好设置"样式），跟着系统浅色 / 深色；各页用表格排版
- 快捷键存法换一下：以前每个功能存"第几个预设"，改成存"哪个键 + 哪几个修饰键"；第一次打开时把你现在的预设换算成键位存下，所以你这台照旧 ⌘1–⌘6。录快捷键时先把 MacKit 自己的快捷键全部暂时摘掉，免得按 ⌘1 直接截了图；撞没撞、能不能设的判断单独写、写单元测试
- 快捷键在菜单里、录制小条提示里、欢迎窗口里显示的写法统一（⌃⌥⇧⌘ 的顺序）
- 开机启动：用 macOS 13 起自带的"登录项"接口（SMAppService），状态也从系统读，系统设置里关掉了这边会跟着显示
- 检查更新：读 GitHub 的"最新发布"接口，只拿版本号、更新说明、下载页地址；版本号比较（1.5.1 和 v2.0.0 谁新）单独写、写单元测试；10 秒连不上就算失败
- 自检：版本号比较、快捷键的各种不让设、预设换算成键位、改快捷键后真的重新注册、设置窗口五页都在；检查更新用假的回答测"已是最新 / 有新版 / 连不上"，不真的联网；开机启动只测状态显示，不真的去加登录项
