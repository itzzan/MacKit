# 台阶 14：剪贴板加强 — 任务单（已拍板）

> 2026-11-05 写，同日你审过：四条都按建议。第二版的第三阶。
> 参考：Paste 的收藏夹（Pinboard）和"连续粘贴"（Paste Stack），Maccy 的"不记某些软件"。

## 现在的样子

- ⌘3 打开剪贴板历史：记最近 200 条，能搜、回车粘贴、⌘P 置顶；置顶的排在最上面，清空历史时留着
- 密码管理器复制的内容不记（它们会打"保密"的标记）；别的软件复制的都记
- 一次只能贴一条

## 做完后你能干什么

### 收藏夹（看第 1 条拍板）

- 剪贴板小窗口上面多一排"全部 | 收藏"，按 Tab 切换
- 选中一条按 ⌘P：收进收藏（再按一次取消）；原来置顶的那些，自动变成收藏
- 收藏的东西：
  - 不会被新复制的挤掉，"清空历史"也不动它
  - 能起个名字：⌘R 改名，比如"公司地址""发票抬头"，小窗口里显示名字，搜名字也能搜到
  - 能拖着排顺序
- 粘贴、纯文字粘贴、⌥1–9、钉成贴图，在"收藏"那一栏里照样能用

### 不记某些软件（看第 2 条拍板）

- 菜单"剪贴板"那一组里多一项：不记「当前正在用的软件」复制的内容，点一下就加进名单
- "剪贴板设置 → 不记录这些软件…"打开一个小窗口：列出名单，能删、能从"应用程序"里再挑几个加进来
- 第一次就在名单里的：钥匙串访问
- 名单里的软件复制的东西不进历史；之前已经记下的不会删（想删可以在小窗口里 ⌘⌫）

### 连续粘贴（看第 3、4 条拍板）

- 开始的两种办法：
  - 菜单"剪贴板 → 开始连续粘贴"，然后按顺序复制几段（比如表格里要填的几个格子）
  - 或者在剪贴板小窗口里按住 ⌘ 点选几条，按 ⌘ 回车：按点的顺序排好
- 屏幕右上角出现一个小条："连续粘贴 1 / 5　下一条：张三…　结束"
- 到要填的地方，每按一次 ⌘V 贴下一条，小条上的数字跟着走；贴完最后一条自动结束
- 中途不想贴了：点小条上的"结束"，或者菜单里"结束连续粘贴"
- 结束后剪贴板恢复成开始之前的内容，不会把你原来复制的东西弄丢

## 这一阶不做

| 功能 | 放到哪 |
|---|---|
| 收藏分组（工作 / 生活……） | 以后再说：先一个收藏夹，能起名字、能排顺序 |
| 粘贴时自动改格式（去空格、大小写） | 以后再说 |
| 收藏同步到别的 Mac | 不做：MacKit 不联网 |
| 连续粘贴时自动按 Tab 跳到下一个格子 | 以后再说：先一条一条按 ⌘V |

## 已拍板（11-05，都按建议）

- "置顶"升级成"收藏"，原来置顶的自动变成收藏
- 不记某些软件：菜单一键"不记当前软件" + 设置里的名单小窗口
- 连续粘贴直接用 ⌘V（只在连续粘贴开着时）
- 还没开始贴时新复制的排到队尾；开始贴以后新复制的照常进历史、不打乱队伍

原来的选项留档：

1. 收藏和置顶
   - A. 把"置顶"升级成"收藏"（建议）：原来置顶的自动变成收藏，⌘P 改叫"收藏"；只有一种概念，不绕
   - B. 两个都留：置顶照旧排在历史最上面，收藏另外一栏

2. 不记某些软件，怎么加进名单
   - A. 菜单里一键"不记当前软件"，加上设置里的名单小窗口（建议）
   - B. 只有设置里的名单小窗口

3. 连续粘贴用哪个键贴下一条
   - A. 直接用 ⌘V（建议）：开着连续粘贴时，MacKit 在你按 ⌘V 的一瞬间把剪贴板换成下一条。要用你已经开过的"辅助功能"权限；只在连续粘贴开着时才这样，结束就完全不碰 ⌘V
   - B. 另用一个快捷键 ⌃⌥V 贴下一条，⌘V 照旧

4. 连续粘贴开着时，你又复制了新东西
   - A. 刚开始、还没贴过时：新复制的排到队尾；已经开始贴了以后：新复制的照常进历史，不打乱队伍（建议）
   - B. 不管什么时候，新复制的都排到队尾

## 怎么验收

1. ⌘3 打开剪贴板，选一段常用的话按 ⌘P：在"收藏"栏里；按 ⌘R 起名"常用开场白"；搜"开场白"能搜到
2. 点"清空历史"：收藏里的还在；复制 201 次新东西（自检帮你测）：收藏的不会被挤掉
3. 在"收藏"栏里拖一条到最上面：顺序变了，关掉再打开还是这个顺序
4. 打开微信，菜单里点"不记「微信」复制的内容"；在微信里复制一段字：剪贴板历史里没有它；在"不记录这些软件…"里把微信删掉，再复制：又记了
5. 菜单"开始连续粘贴"，依次复制"张三""男""28"；到一个文本框里按三次 ⌘V：依次贴出张三、男、28；小条自动消失；再按 ⌘V：贴的是开始之前剪贴板里的东西
6. 剪贴板小窗口里 ⌘ 点三条，⌘ 回车：同样一条条贴出来；贴到一半点"结束"：⌘V 恢复正常

## 技术要点（备忘）

- 收藏：现在每条历史已经有"置顶"标记，改成"收藏"并加"名字""收藏里的顺序"两样；老的历史文件读进来时，置顶的自动当成收藏。清空和 200 条上限本来就跳过置顶的，收藏沿用
- 小窗口：上面加"全部 | 收藏"的切换（统一样式的分段按钮），Tab 切换；收藏栏里允许拖动排序；⌘R 在那一行里直接改名
- 不记某些软件：每条历史本来就记着是哪个软件复制的（软件的身份编号），名单存的就是这个编号；判断"当前正在用的软件"用系统给的最前面那个软件；名单小窗口用普通窗口 + 统一按钮样式
- 连续粘贴（拍板 A）：开着时在系统里挂一个"按键钩子"，只认 ⌘V：在 ⌘V 送到软件之前把剪贴板换成下一条，然后照常放行；贴完或结束就把钩子摘掉、剪贴板换回开始前的内容。MacKit 自己往剪贴板写的东西打了标记，不会被重新记进历史
- 小条用统一的浮动条样式，放在屏幕右上角、不挡菜单栏；不抢焦点
- 自检：老文件里的置顶读成收藏；收藏不受清空和上限影响；改名后能搜到；排序存下来；名单里的软件复制的被跳过；连续粘贴：模拟三次 ⌘V，剪贴板依次换成三条、结束后换回原来的（用私有剪贴板，不碰你真正的剪贴板，也不真的挂按键钩子）
