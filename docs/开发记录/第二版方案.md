## 一、第二版想做到什么

一句话：**截图标注更好改、剪贴板更好管、截出来的图更好看，新用户更好上手。**

第一版是"什么都有"，第二版是"常用的那几样用着更顺手"。

## 五、技术上要先知道的（备忘）

- 标注升级要把现在"画完就定死"的标注改成"能再选中"的：每样东西记住自己的位置和样式，点到哪个就把哪个拿出来改。撤销重做要跟着改
- 截图美化：背景、圆角、阴影都在导出图片时画上去，不动原图；做几套预设渐变，再加一个"跟着截图的主色自动配"
- 收藏夹：剪贴板历史现在存在 ~/Library/Application Support/MacKit/Clipboard，收藏单独存一份，清空历史不影响收藏
- 翻译：macOS 15 自带的"翻译"能力（Translation），在电脑上本地翻，要用户先在系统设置里下载语言
- 设置窗口：现在的设置都按"第几个预设"存，改成随便设快捷键时要把老设置搬过去，你这台的 ⌘1–⌘6 不能乱
- 开机启动：用 macOS 13 起自带的"登录项"接口，用户在系统设置里也能看到、能关
- 检查更新：读 GitHub 上最新发布的版本号和本机比；只读不下载
