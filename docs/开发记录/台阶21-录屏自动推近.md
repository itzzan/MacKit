# 台阶 21：录屏自动推近（点鼠标的地方自动放大、跟着鼠标走）— 任务单（已拍板）

> 2026-11-06 写，同日你审过：四条都按建议。第三版的第三阶，第三版里最难的一阶。
> 参考：Screen Studio 这类录教程的软件，录完自动在你点的地方推近，看的人一眼知道你在点哪。

## 现在的样子

- 录屏录的是整块区域，屏幕大、字小的时候，看视频的人找不到你在点哪
- 录完的预览窗口能剪头剪尾、存成 GIF，但画面只能原样
- MacKit 录的时候不记鼠标在哪、点了哪（鼠标和点击圈是系统直接画进视频的）

## 做完后你能干什么

### 录的时候

- 和现在一样录（框选区域或整屏），什么都不用多点
- MacKit 顺手记下鼠标在哪、什么时候点了一下（只记位置和时间，存在 MacKit 自己的文件夹里，不联网；见下面技术要点里的"存哪"）

### 录完在预览窗口里

- 预览窗口多一个勾"自动推近"，旁边能选放大多少：1.5 倍、2 倍（默认）、2.5 倍
- 勾上以后直接播放就能看到效果：
  - 你点鼠标的地方，提前一点点开始推近，半秒推到位
  - 连着点的时候一直推近，镜头平滑地跟着鼠标走，靠边时不会推出画面
  - 停下 2 秒不点，慢慢拉回全景
- 满意了点"保存"：另存一份"原文件名-推近.mp4"，原视频不动；声音原样带上
- 同时剪了头尾：存出来的是剪过、又推近的那份
- 勾着推近点"存成 GIF"：GIF 也是推近的
- 不勾：一切和现在一样

### 什么时候用不了

- 录的是单个窗口：窗口会被拖来拖去，鼠标位置对不上，"自动推近"灰着，写着原因
- 2.2 以前录的老视频：没有鼠标记录，同样灰着

## 这一阶不做

| 功能 | 放到哪 |
|---|---|
| 自己在时间线上拖，决定哪一段推近、推多大 | 以后再说：先全自动 |
| 跟着打字的地方推近 | 不做：系统不告诉别的软件文字光标在哪 |
| 鼠标轨迹变平滑、鼠标放大（Screen Studio 的"平滑光标"） | 以后再说：鼠标是系统画进视频的，要改得重画 |
| 给视频加背景、圆角、阴影（像截图美化那样） | 以后再说 |
| 录单个窗口时推近 | 不做：窗口位置会变 |
| 录屏前就开、录完直接是推近版 | 不做（第 3 条拍板：录完再开，看得到效果） |

## 已拍板（11-06，都按建议）

- 点鼠标就推近；两次点击不到 2 秒算一段，一直推着、跟着鼠标走；停下 2 秒不点就拉回全景
- 默认 2 倍，预览窗口里能换 1.5 / 2 / 2.5 倍
- 在录完的预览窗口里勾"自动推近"，播放就能看到效果
- 推近后保存：另存一份"原文件名-推近.mp4"，原视频不动

原来的选项留档：

1. 什么时候推近
   - A. 点鼠标就推近；连着点（两次之间不到 2 秒）一直保持、跟着鼠标走；停下 2 秒不点就拉回全景（建议）：只在你"做事"的时候推近，看的人不晕
   - B. 再加上：鼠标停在一处超过 1 秒也推近：更像在"讲解"，但看网页、想事情时也会推近，画面晃得多

2. 放大多少
   - A. 默认 2 倍，预览窗口里能换 1.5 / 2 / 2.5 倍（建议）：大屏幕上录的换大一点，小区域录的换小一点
   - B. 固定 2 倍，不让选：少一个选项

3. 在哪开
   - A. 录完的预览窗口里勾"自动推近"，播放就能看到效果，满意再保存（建议）：不满意就不勾，原视频一点不受影响
   - B. 录屏前的控制条上开，录完直接就是推近版：少一步，但看不到没推近的样子，不满意只能重录

4. 推近后保存
   - A. 另存一份"原文件名-推近.mp4"，原视频不动（建议；第三版方案写的就是原视频不动）
   - B. 和剪头剪尾一样：存好后把原来的放进废纸篓，文件夹里不多一个

## 怎么验收

1. ⌘4 框一块区域开始录：依次点三个按钮（隔一秒点一个），停 3 秒，再点另一个地方，停止
2. 预览窗口勾"自动推近"：播放时点按钮的地方推近 2 倍，三下之间镜头平滑地跟着走；停的那 3 秒里拉回全景；最后那一下又推近
3. 换成 2.5 倍、1.5 倍各看一遍
4. 点"保存"：影片文件夹里多一个"…-推近.mp4"，原来的还在；打开新的那份，声音还在
5. 剪掉开头再保存：新的那份是剪过又推近的
6. 勾着推近点"存成 GIF"：GIF 也是推近的
7. 录一个单个窗口：预览里"自动推近"灰着，写着原因；打开以前录的老视频也一样

## 技术要点（备忘）

- 记鼠标：录的时候每秒 30 次读一下鼠标在哪，点击用系统的全局鼠标事件（只看鼠标、不看键盘，不用新权限）；换算成视频画面里的位置（框选区域相对屏幕在哪、Retina 倍数）；暂停的时候不记，时间按"视频里的时间"算（暂停那段不算）
- 存哪：几十 KB 的小文件，放在 ~/Library/Application Support/MacKit/RecordTracks，按视频文件名对上，只留最近 20 次录屏的；不放进影片文件夹，免得多出一堆看不懂的文件
- 算推近（纯计算，写单元测试）：每次点击 → 提前 0.3 秒开始推、0.5 秒推到位；两次点击不到 2 秒算一段，一直推着；最后一下之后 2 秒开始拉回、0.8 秒拉完；镜头中心跟着鼠标做平滑（不跟每一点小抖动），靠边时整个框留在画面里
- 播放和导出：用系统的视频合成，每一帧按算好的框裁剪放大；预览窗口里直接实时看；导出 H.264，声音原样带上；GIF 从推近后的画面做
- 自检：推近曲线（单元测试：什么时候开始、到位、保持、拉回，靠边不出画面）；点击时间换算到视频时间（有暂停时）；用代码画一段 2 秒的小视频 + 一份假的鼠标记录 → 导出推近版，查画面确实放大了、尺寸和时长对；没有记录时勾是灰的；另存不覆盖原视频
