## 做完后你能干什么

### 改已经画好的东西

- 鼠标移到画好的箭头、框、圈、笔画、马赛克、文字、序号上，指针变成小手；点一下就选中（看第 1 条拍板）
- 选中后，四周出现虚线框和小方块：
  - 拖它本身：挪位置
  - 拖小方块：改大小（矩形、椭圆、马赛克、模糊、画笔、荧光笔）
  - 箭头只有头尾两个小圆点：拖哪头，哪头就动，方向和长短一起改
  - 文字、序号：只能挪；字大小、圈大小用工具栏的"细 / 中 / 粗"改
- 选中时点工具栏的颜色、粗细：改的是选中的那个（同时也记成下次画的默认）
- ⌫ 或 Delete：删掉选中的
- 刚画完的那个自动保持选中，马上就能调（看第 2 条拍板）
- 点空白处：取消选中；按住拖：照常画新的
- 所有改动都能 ⌘Z 撤销、⇧⌘Z 重做；拖一次只算一步
- Esc：有选中的先取消选中；没有选中的照旧取消截图

### 模糊打码

- 工具栏多一个"模糊"（快捷键 B，看第 3 条拍板）：框住的地方糊成一片，比马赛克自然
- 细 / 中 / 粗 = 轻糊 / 中糊 / 重糊
- 导出的图片和屏幕上看到的一模一样

## 怎么验收

1. ⌘1 截一块，画一个箭头故意画歪；鼠标移到箭头上变小手，点一下出现头尾两个小圆点；拖尾巴那头，把箭头摆正
2. 画一个框：画完就带着小方块；拖右下角改大小、拖边挪位置；点工具栏的红色，框变红；点"粗"，框变粗
3. 选中一笔画笔，按 ⌫ 删掉；⌘Z 回来；⇧⌘Z 又删掉
4. 选中一个东西按 Esc：只是取消选中；再按 Esc：取消截图
5. 用"模糊"框住一段字：糊得看不清；和旁边的马赛克比一比
6. 改完点完成，到微信里粘贴：是改过以后的样子
7. 钉一张贴图，右键"标注"：同样能选中、拖动、改颜色、删除

## 技术要点（备忘）

- 现在每样标注都记着自己的点（框的两个角、箭头的头尾、笔画的一串点），所以能重新拿出来改，不用重写标注的存法
- 点没点中（纯计算，写单元测试）：框、圈只认线条附近（线宽一半 + 4 点的余量），箭头和笔画看离线段多近，马赛克、模糊、文字、序号认整块；叠在一起取最上面那个
- 改大小：框类复用选区那 8 个小方块的算法；画笔、荧光笔按外框等比例拉伸所有点；箭头拖端点
- 撤销：拖之前存一份，拖的过程中不记，松手才算一步
- 模糊：从冻住的截图里取那一块做高斯模糊（和马赛克一样，先在整张图上算好缓存），屏幕显示和导出共用一套
- 贴图标注用同一个编辑器，所以自动有这些功能；按 Esc 放弃这次画的规则不变
- 自检：用假的鼠标点击、拖动走一遍"选中 → 挪 → 改大小 → 改颜色 → 删 → 撤销"；导出图片检查模糊过的地方确实糊了（相邻像素差别变小），没框的地方一点不变
