# 台阶 23：剪贴板小改进（收藏分组、改格式粘贴、连续粘贴自动跳格）— 任务单（已拍板，11-06 验收通过）

> 2026-11-06 写，同日你审过：四条都按建议。第三版的第五阶。
> 参考：Paste 的多个收藏夹（Pinboards），Pastebot 粘贴前改格式（Filters）。

## 现在的样子

- ⌘3 打开剪贴板历史，上面"全部 | 收藏"，Tab 切换；收藏能起名字（⌘R）、能拖着排顺序（台阶 14）
- 收藏只有一个大筐：收得多了（公司地址、发票抬头、常用回复、家里地址……）混在一起不好找
- 从 PDF 复制一段字，贴出来每行都断开，要自己一行行删换行；⇧回车只去掉字体、颜色这些格式，去不掉断行
- 连续粘贴：每按一次 ⌘V 贴下一条，但贴完要自己按 Tab 跳到下一个格子

## 做完后你能干什么

### 收藏分组

- "收藏"栏里，搜索框下面多一排分组小按钮："所有收藏 | 工作 | 生活 | ＋"
- 选中一条按 ⌘G：弹出小菜单，挑放进哪个组；菜单里也有"新建分组…"（借搜索框打名字，和 ⌘R 起名一样）和"不分组"
  - 在"全部"栏里对还没收藏的按 ⌘G：先收藏、再放进组
- 一条收藏放在一个组里（像文件夹）；"所有收藏"里照样看得到全部，每条下面一行带着组名
- 点组名或按 Tab 切换：全部 → 所有收藏 → 工作 → 生活 → 回到全部（⇧Tab 倒着走）
- 在组里：搜索只搜这个组；回车粘贴、⇧回车纯文字、⌥1–9、⌘2 钉成贴图、拖着排顺序都照样能用
- 右键点组名：改名、删掉这个组（里面的收藏不删，变成"不分组"，还在"所有收藏"里）
- 取消收藏（⌘P）的那条，也就离开了它的组
- 一开始没有组，你自己建；退出再打开，组都在

### 粘贴时改格式

- 剪贴板小窗口里选中一条文字，按 ⌘T：弹出"改格式粘贴"小菜单，按数字或点一下：
  1. 去掉断行：一行行接成一段，空一行的地方还是分段（从 PDF 复制的就用它）。中文接起来不加空格，英文接起来中间加一个空格
  2. 去掉多余空格：连着的空格压成一个，每行首尾的空格去掉，好几个空行压成一个
  3. 全大写（hello → HELLO）
  4. 全小写
  5. 每个词首字母大写（hello world → Hello World）
- 选完直接贴到原来的软件里，贴的是纯文字
- 历史里那条还是原样（改过的不另记一条），下次还能换别的格式贴
- 中文没有大小写，3–5 只改里面的英文字母
- 图片、文件没有这个菜单（按 ⌘T 提示"只有文字能改格式"）

### 连续粘贴贴完自动跳格

- 连续粘贴的小条上多一个开关"贴完按 Tab"，默认关着（和现在一样）
- 打开后：每按一次 ⌘V，贴好这一条，MacKit 接着替你按一下 Tab，光标跳到下一个格子；你只管一直按 ⌘V
- 开关记住上次的选择；设置窗口"剪贴板"那页也能改
- 在 MacKit 自己的窗口里按 ⌘V 照旧不算、也不跳

## 这一阶不做

| 功能 | 放到哪 |
|---|---|
| 一条收藏同时放进好几个组（像标签） | 不做（第 2 条拍板：一个组，像文件夹） |
| 拖着排分组的先后 | 以后再说：按建的先后排 |
| 改格式一次做好几样（去断行 + 全大写） | 不做：一次一种 |
| 每次粘贴都自动改格式 | 不做：容易把不想改的也改了 |
| 不开小窗口直接改格式粘贴的全局快捷键 | 不做（第 3 条拍板：只在小窗口里 ⌘T） |
| 繁体简体、全角半角互换 | 以后再说 |
| 连续粘贴贴完按回车（表格里往下填） | 不做（第 4 条拍板：只有 Tab） |
| 收藏同步到别的 Mac | 不做：MacKit 不联网 |

## 已拍板（11-06，都按建议）

- 收藏栏里一排分组按钮，点一下或按 Tab 只看这一组
- 一条收藏只放进一个组（像文件夹）
- 改格式只在剪贴板小窗口里：选中按 ⌘T 挑格式，不加全局快捷键
- 连续粘贴自动跳格只有 Tab，默认关

原来的选项留档：

1. 分组怎么摆
   - A. 收藏栏里一排分组按钮，点一下或按 Tab 只看这一组（建议）：组多了也不乱，⌥1–9 对着这一组的前 9 条
   - B. 不分开看，按组一段一段排下来，每段上面一个小标题（像通讯录的 A、B、C）：一眼看全，但收藏多了要往下滚

2. 一条收藏能放进几个组
   - A. 一个，像文件夹（建议）：简单，不绕
   - B. 好几个，像标签：同一个地址既算"工作"又算"生活"，但 ⌘G 的菜单要变成打勾多选，删组、排顺序也更绕

3. 改格式怎么用
   - A. 只在剪贴板小窗口里：选中按 ⌘T 挑格式（建议）：不多占全局快捷键，五种格式都能挑
   - B. 再加一个全局快捷键 ⌃⇧V：不打开小窗口，直接把剪贴板里的字"去掉断行"贴出来。从 PDF 复制最快，但这个键要一直占着（可能和别的软件撞）

4. 自动跳格按什么键
   - A. 只有 Tab（建议）：填网页表单、表格往右填都用它；简单
   - B. Tab 或回车二选一：表格里往下填用回车；但在网页表单里按回车可能直接把表单提交出去

1. ⌘3 → Tab 到"收藏" → 选一条按 ⌘G → "新建分组…"打"工作"回车：搜索框下面出现"工作"，这条在里面；再建一个"生活"，放一条进去

## 技术要点（备忘）

- 分组：每条收藏多记一个"在哪个组"（存组的编号，改组名不用动每一条）；分组表（编号、名字、先后）另存一个小文件 Clipboard/groups.json，原来的 index.json 格式不变，老的历史照样读，读进来都是"不分组"
- 删组：组里的收藏清掉"在哪个组"；取消收藏时也清掉。组里拖着排顺序：只在这一组的几条之间换位置，"所有收藏"的顺序跟着变
- 分组按钮那一排只在收藏栏里出现，组多了一排放不下就左右滚；小窗口大小不变，列表让出一排的高度。下面的提示加上"⌘G 分组　⌘T 改格式粘贴"
- 改格式：纯计算放进 ClipboardText（有单元测试）
  - 去断行：两行之间，前一行最后一个字或后一行第一个字是中文、日文或全角标点，就直接接上（韩文词之间本来有空格，照英文加空格）；不然中间加一个空格。行尾是英文单词断开的"-"，直接接上、"-"留着（宁可多一个"-"，也不把 well-known 拼成 wellknown）。只有空白的行算分段，留一个空行。Windows 的换行（\r\n）也认
  - 首字母大写只改每个英文词的第一个字母，别的字母不动（iPhone 不会变成 Iphone）
- 改好的字按纯文字放进剪贴板，带 MacKit 自己的标记（台阶 4 起就有），不会被记进历史
- 跳格：连续粘贴的按键钩子里，⌘V 照常放行后等 0.15 秒（让软件先贴好），MacKit 替你按一下 Tab；这个 Tab 钩子不管，原样放行。开关存在设置里，默认关
- 自检（不显示、私有剪贴板、临时文件夹，不碰你的历史）：建组、放进组、改名、删组后收藏还在、取消收藏离开组、存盘再读组都在、老历史文件读进来都不分组；Tab 走一圈、⇧Tab 倒着走、组里搜索、组里 ⌥1、组里排顺序；"全部"里 ⌘G 先收藏再进组；五种格式的样例（中英混排的 PDF 断行、空行分段、连字符、\r\n、大小写）；改格式粘贴后剪贴板里是改好的、历史里不多一条；图片按 ⌘T 不改；跳格：开着时 ⌘V 后记一次"要按 Tab"（自检里不真按键），关着不记、在 MacKit 自己窗口里不记
- 没法自动检查的：真的替你按 Tab 跳到下一个格子（要真的按键，自检不碰你的键盘），要你验收时试
- 版本号 2.5.0（只装你这台，第三版做完一起发布成 3.0）
