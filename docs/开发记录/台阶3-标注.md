## 做完后你能干什么

- 按 ⌘1 框选完松手，框不会马上消失，而是停在屏幕上，旁边出现一排工具栏（和 Snipaste 一样）
- 画之前可以先调整框：拖 8 个小方块改大小，拖框里面挪位置，方向键一次挪 1 个点
- 在框里直接画：

| 工具 | 用来干什么 | 快捷键 |
|---|---|---|
| 矩形 | 圈出重点 | R |
| 椭圆 | 圈出重点 | E |
| 箭头 | 指向某处 | A |
| 画笔 | 随手画 | P |
| 荧光笔 | 半透明的粗笔，像拿记号笔划重点 | H |
| 马赛克 | 框一块打码，盖住密码、手机号 | M |
| 文字 | 点一下就能打字，中文输入法照常用。写好的字用文字工具点一下（或没选工具时双击）能接着改，改成空白就删掉 | T |
| 序号 | 点一下放一个带数字的圆圈，1、2、3 自动往上加 | N |

- 每种工具都能选颜色（红、橙、黄、绿、蓝、黑、白，默认红色）和粗细（细、中、粗）
- 画错了：⌘Z 撤销，⇧⌘Z 重做
- 画完后，工具栏最右边几个按钮决定去哪：

| 按钮 | 做什么 | 快捷键 |
|---|---|---|
| ✓ 完成 | 复制到剪贴板，同时存文件（和现在一样） | 回车、⌘C，或没选工具时在框里双击 |
| 📌 贴图 | 不复制，直接钉在原位置（台阶 2 说好的"框选完直接贴"） | ⌘2 |
| 💾 另存为 | 自己选位置和文件名。冻住的画面会先收起来，点取消就原样放回来接着编辑 | ⌘S |
| ✕ 取消 | 什么都不留 | Esc |

- 截出来的图是 Retina 原始清晰度，标注也是
- 画了第一笔以后框就固定了，免得标注和框错位；想重新框就 Esc 再截一次
- 再按一次当前工具的快捷键（或点它）= 放下工具，这时又能拖框、双击完成
- 颜色和粗细会记住，下次截图还是上次用的
- MacKit 万一卡住：按 ⌃⌥⌘Q 紧急退出（菜单最下面也写着）

## 技术要点（备忘）

- 新积木 MacKit/Tools/Annotate/：标注画板，只管"一张图 + 一堆标注"，截图和以后的贴图标注都用它
- 标注存成一条条记录（类型、颜色、粗细、坐标），撤销和重做就是在两个列表之间挪；画面和最终导出用同一套画法，保证看到的就是导出的
- 导出时按像素画：截图是 2 倍图，标注也按 2 倍画，线条不发虚
- 马赛克取的是冻住的原画面，不会把别的标注一起打码
- 文字用系统的文本框，中文输入法、⌘V 粘贴都能用；打完变成一条文字标注
- 选区改大小的计算单独放，写单元测试；自检用假图片画上各种标注，导出后检查像素颜色和位置对不对

## 11-04 第一次验收卡死

现象：点工具栏的 💾（另存为）后，屏幕像卡住了。保存窗口看不到，MacKit 关不掉，贴出来的图也拖不动。

原因：
- 保存窗口是系统另一个进程画的，压不过冻住的画面，被挡在了下面
- MacKit 用的是"一直等到你选完位置"的方式打开保存窗口，等的却是一个看不见的窗口
- 你又按了 ⌘2，截图贴出来、冻住的画面收掉了，但 MacKit 接着把自己藏起来，连那个保存窗口也一起藏了，于是一直卡在等待里

处理：
- 我先结束了 MacKit 进程，冻住的画面随之消失
- 另存为改成：先收起冻住的画面，再用不卡人的方式打开保存窗口；点取消就把画面和标注放回来
- 保存窗口开着时，⌘2、Esc、完成都不响应；有对话框开着时 MacKit 不再把自己藏起来
- 贴图的另存为、改保存位置也换成不卡人的方式
- 新增紧急退出 ⌃⌥⌘Q：卡住时全局快捷键照样有效，按它直接退出

## 11-04 第二次验收：文字工具的两个问题

问题一：在白底上打字时看不到拼音。

- 原因：输入法正在拼写、还没选字的拼音，不会让输入框变宽。我只在"字定下来"时才调宽度，输入框一直只有 8 个点宽，拼音几乎全被裁掉。选完字输入框才变宽，所以汉字能看到
- 处理：拼写中、删字、粘贴时都重新量宽度；编辑中的输入框加一层半透明衬底，打在什么颜色的底上都看得清（最终的图上没有衬底）

问题二：写好的字不能再改。

- 处理：用文字工具点已有的字，或没选工具时双击它，原文回到输入框接着改；改成空白就删掉
- 撤销改成"每次改动前存一份"，加、改、删文字都能 ⌘Z 撤销、⇧⌘Z 重做

自检新增 15 条，把这两个情况都复现了一遍：打拼音时输入框变宽、拼音真的画出来、拼音没被提前定下来、选字、点已有的字接着改、撤销重做、删光、改颜色粗细。
