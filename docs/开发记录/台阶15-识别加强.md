# 台阶 15：识别加强（翻译、最近的颜色）— 任务单（已拍板）

> 2026-11-05 写，同日你审过：四条都按建议。第二版的第四阶。
> 翻译用的是 macOS 15 自带的"翻译"（和系统里右键"翻译"是同一个），在你电脑上本地翻；MacKit 自己照旧一点不联网。

## 现在的样子

- ⌘5 框一块：认出的字自动复制，弹出结果窗口（能改、去掉换行、复制；有二维码时能打开链接）
- ⌘1 截图时鼠标指着一个颜色按 C：复制它的 HEX（或 RGB）；复制完就没了，下次要同一个颜色还得再取

## 做完后你能干什么

### 识别完翻译

- 结果窗口里多一个"翻译"按钮（看第 1 条拍板）；点一下，窗口下半部分出现译文
- 自动判断方向（看第 2 条拍板）：认出的是中文就翻成英文，别的语言（英、日、韩……）翻成中文；旁边有一个"翻成：中文 / 英文 / 日文……"的小菜单，想换就换
- 翻好后译文自动复制到剪贴板（原文还在剪贴板历史里）；"复制原文""复制译文"两个按钮都在
- 原文改了几个错字，再点"翻译"就按改过的重新翻
- 菜单"识别"那一组里多一项"识别并翻译（框选）"：框完直接出译文（看第 3 条拍板）
- 第一次翻某种语言时，系统会问要不要下载这种语言（几十 MB，系统自己下，下好以后不联网也能翻）；结果窗口里会写清楚

### 最近的颜色（看第 4 条拍板）

- ⌘1 截图时按 C 取过的颜色记下来，最近的 20 个
- 菜单"截图"那一组里多一项"最近的颜色"：每一项前面一个小色块，后面是 HEX；点一下复制；按住 ⌥ 看到的是 RGB，点了复制 RGB
- 同一个颜色取两次不会记两遍，只是挪到最前面
- 最下面有"清空"

## 已拍板（11-05，都按建议）

- 译文显示在结果窗口下半部分，能改、能复制
- 方向自动（中文 → 英文，别的 → 中文），旁边小菜单能换
- 菜单里加"识别并翻译（框选）"，不加快捷键
- 最近的颜色存下来，重启后还在

原来的选项留档：

1. 译文显示在哪
   - A. 结果窗口下半部分直接显示（建议）：能改、能复制，和原文上下对照
   - B. 弹系统自带的翻译小窗（和在别的软件里右键"翻译"一样）：省事，但不能改，样子和 MacKit 不一样

2. 翻译方向
   - A. 自动：中文翻成英文，别的翻成中文；想换用旁边的小菜单（建议）
   - B. 每次自己选

3. 要不要"识别并翻译"一步到位
   - A. 菜单里加"识别并翻译（框选）"，不加快捷键（建议）：⇧⌘5 是系统自带截图工具的快捷键，不能用；⌘5 识别后点一下"翻译"也就多一步
   - B. 再加一个快捷键 ⌥⌘5 = 框选直接翻译

4. 最近的颜色记多久
   - A. 存下来，重启后还在（建议）：颜色不算隐私
   - B. 只记这次打开 MacKit 以来的

## 怎么验收

1. ⌘5 框一段英文网页：结果窗口里点"翻译"，下半部分出现中文；到微信里 ⌘V 是译文
2. 框一段中文：点"翻译"，翻成英文；在小菜单里换成"日文"：变成日文
3. 第一次翻某种没下载过的语言：系统问要不要下载，点下载后能翻出来
4. 在原文里改一个字再点"翻译"：译文跟着变
5. 菜单"识别并翻译（框选）"：框完直接出译文
6. ⌘1 截图时取三个颜色（每次按 C）：菜单"最近的颜色"里有这三个，最新的在最上面；点一个，到别处粘贴出 HEX；按住 ⌥ 再点，粘贴出 RGB
7. 退出 MacKit 再打开：最近的颜色还在

## 技术要点（备忘）

- macOS 15 的翻译只能从 SwiftUI 里拿到"翻译会话"：在结果窗口里放一块看不见的 SwiftUI 小视图，挂上系统的"翻译任务"；要翻的时候给它一个配置（从哪种语言到哪种），它在你电脑上翻好交回来。macOS 26 才能直接调用，到时候再简化
- 翻之前先问系统这两种语言"装了没有 / 能下载 / 不支持"：装了直接翻；能下载就让系统弹下载提示；不支持就在窗口里说明
- 认出来的是哪种语言：用系统自带的语言识别（NaturalLanguage）；判断方向的那一步单独写、写单元测试
- 最近的颜色：存成 20 个 RGB 数字（不存截图），同一个颜色挪到最前；纯逻辑写单元测试；菜单里的小色块现画
- 自检：方向判断、颜色列表的增删和上限、菜单项（HEX、按住 ⌥ 的 RGB）、结果窗口里有"翻译"按钮和语言小菜单、用假的"翻译员"走一遍"点翻译 → 出译文 → 自动复制"（私有剪贴板）。真的翻译要看你电脑上装没装语言包：装了的话我用一句话实测一次（不弹窗口）；没装就不测，留给你验收时试
