## 现在的样子

- ⌘6 测量：鼠标停在哪，就往四个方向自动找边，十字线标出宽高；拖框量大小；单击或 C 复制"宽 × 高"（台阶 7）
- 想量两个按钮隔多远：得把鼠标放在两个按钮中间的空白处，十字线横着那段才是间距，竖着那段常常一直量到屏幕边上；也看不出两个东西有没有对齐
- ⌘1 截图时鼠标指着一个颜色按 C：复制它；菜单"截图 → 最近的颜色"记着最近 20 个（台阶 15）
- 一套颜色（品牌色、网页配色）没地方存，没法起名字，也没法一次拿走

## 做完后你能干什么

### 量两个东西的间距

- ⌘6 测量时，鼠标放在第一个东西上（比如按钮的空白处，别放在字上），按一下空格：它被蓝框框住，标着宽高——"记下"了
- 鼠标移到第二个东西上：它也自动框出来，两个之间画出间距线，标着多少点
  - 左右排着的：标横着的间距；上下排着的：标竖着的间距；斜着摆的：横竖都标
  - 一个在另一个里面（按钮在卡片里）：标出上下左右四个边距，一眼看出是不是居中
- 单击或按 C：复制量到的间距（比如"12"；斜着的是"横 12、竖 8"；在里面的是"上 12 下 12 左 16 右 16"），退出测量
- 再按空格：换成鼠标下面这个当第一个；Esc：先取消记下的，再按一次才退出测量
- 原来的十字线、拖框量大小照旧

### 对齐线

- 记下第一个以后，第二个的边和它对齐（左边、右边、顶边、底边、横着的中线、竖着的中线），就画一条贯穿两个框的对齐线
- 差一点没对齐（4 点以内）：画虚线，写"差 2 点"——界面上歪了一点的地方一眼就能看出来

### 调色板

- 菜单"截图"那一组里多一项"调色板…"，打开一个小窗口：
  - 上面挑调色板（可以有好几个，比如"品牌色""网页配色"），能新建、改名、删除
  - 中间是这个调色板里的颜色：色块、名字、HEX、RGB；双击名字起名（"主色""强调色"）；选中点"删掉选中的"；每一行后面的"复制"复制 HEX
  - 加颜色：
    - 下面一排"最近的颜色"（⌘1 取过的），点一下加进来
    - "取色"按钮：系统自带的放大镜，指哪取哪
    - 打一个 HEX（比如 #FF3B30）加进来
  - "导出"：复制成文字，三种格式挑——纯文字（"主色 #FF3B30"一行一个）、CSS 变量、JSON
- ⌘1 截图时指着一个颜色按 S：存进调色板（第 3 条拍板），不退出截图，可以接着指下一个再按 S；放大镜下面写"✓ 已存进「品牌色」"
- 存进的是最近打开的那个调色板；一个都没有时自动建一个"我的颜色"
- 调色板存在设置里（只存颜色数字和名字），重启后还在

|---|---|
| 两点之间的直线距离（斜着量） | 以后再说 |
| 屏幕标尺、拖出来一直留着的参考线 | 以后再说 |
| 调色板里拖着排颜色的先后 | 以后再说：按加进来的先后排 |

| 导出存成文件、放进系统颜色面板 | 不做（第 4 条拍板：复制到剪贴板） |

3. ⌘1 取色时怎么存进调色板

4. 导出成什么
   - A. 复制到剪贴板，三种格式挑：纯文字、CSS 变量、JSON（建议）：贴到哪都行，要文件就贴进文本编辑存一下
   - B. 再加"存成文件"和"放进系统颜色面板"（Pages、Keynote 这些软件的颜色面板里也能直接用这套颜色）：多两样，菜单长一点

## 怎么验收

1. 打开一个有两个并排按钮的网页（或者系统设置里随便一页），⌘6，鼠标放在第一个按钮的空白处按空格：按钮被蓝框框住；移到第二个按钮上：两个之间标出间距；单击，到备忘录里粘贴出这个数
2. ⌘6，记下一个卡片（或一大块面板），鼠标移到它里面的按钮上：标出上下左右四个边距；找两个上下排着的按钮：左边对齐的有一条对齐线
3. 记下一个以后按 Esc：蓝框没了、还在测量；再按 Esc：退出
4. ⌘1，鼠标指到一个颜色按 S：放大镜下面写"已存进「我的颜色」"，截图没退出；再指两个颜色按 S；Esc 退出
5. 菜单"截图 → 调色板…"：看到"我的颜色"里有刚才那三个；改名成"品牌色"，双击第一个颜色起名"主色"；点"取色"再从屏幕上取一个；点"导出 → CSS 变量"，到备忘录里粘贴出 `--主色: #……;` 这样的几行
6. 退出 MacKit 再打开：调色板和名字都在

## 技术要点（备忘）

- "东西"的框：从鼠标那一点往四个方向找边（和现在的十字线一样），量到的左右上下就是框；所以要指在按钮的空白处，指在字上框的就是那个字
- 间距、边距、对齐的计算单独写成纯计算（屏幕像素算，显示时换成点），有单元测试：左右排、上下排、斜着、一个在另一个里面、叠在一起；对齐比六条线（左、右、横中线、顶、底、竖中线），中线差半个像素也算对齐；差 4 点以内算"差一点"
- 画法：第一个蓝色实框，第二个浅蓝框；间距线两头带短横、中间标数字；对齐线红色细线贯穿两个框，差一点的橙色虚线 + "差 N 点"；下面的提示加"空格 记下这个，再指别的量间距"
- 调色板：存在设置里（JSON：调色板名字、每个颜色的 0xRRGGBB 数字和名字），记着"最近打开的是哪个"；新建时名字重复就加"2"
- 调色板窗口用普通窗口 + 统一按钮样式；颜色列表是表格（色块、名字、HEX、RGB）；"取色"用系统自带的取色放大镜（NSColorSampler，不用新权限），颜色换算成 sRGB，和 ⌘1 取色一样
- ⌘1 截图里按 S：只在"还没框选、放大镜开着"的时候有用（框选以后 S 不归它管）；放大镜下面那行字临时换成"✓ 已存进「…」"
- 导出：CSS 变量名用颜色的名字（空格换成"-"），没起名字的叫 --color-1、--color-2；JSON 里有名字、HEX、RGB
- 自检（不显示、不碰你的剪贴板、设置测完换回去）：用造出来的图片（两块黑方块）量间距、四个边距、对齐和差一点；按空格记下、Esc 先取消记下的、单击复制间距；调色板新建、改名、删除、加颜色、起名、删颜色、存盘再读；三种导出的文字；⌘1 按 S 存进去、不退出、没有调色板时自动建"我的颜色"；菜单里有"调色板…"
- 没法自动检查的：系统取色放大镜（要真的点屏幕）、真实网页上找边准不准，要你验收时试
- 版本号 2.6.0（只装你这台，第三版做完一起发布成 3.0）
