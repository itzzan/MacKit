## 做完后你能干什么

### 防休眠

- MacKit 菜单里"防休眠"：30 分钟 / 1 小时 / 2 小时 / 一直开着 / 关掉
- 开着时，菜单栏的扳手换成一个咖啡杯；菜单里写着"防休眠中，还剩 42 分钟"，到时间自动关
- 录屏时自动防休眠，录完恢复原样（看第 3 条拍板）
- 做不到的：合上笔记本盖子还是会睡（除非接着电源和外接显示器），这是苹果的规定

### 延时截图

- 截图菜单里"延时截图"：3 秒 / 5 秒 / 10 秒
- 屏幕中间倒数 3、2、1，你趁这几秒打开要截的菜单、把鼠标放到会出提示的地方；倒数完和 ⌘1 一样冻住屏幕、框选、标注
- 倒数时按 Esc 取消

### 系统状态

- 点开 MacKit 菜单，最上面几行就是：
  - CPU 23%
  - 内存 已用 18.2 GB / 共 24 GB
  - 网速 ↓ 1.2 MB/s　↑ 80 KB/s
  - 磁盘 剩余 312 GB
  - 电池 86%，充电中
- 菜单开着时每秒刷新一次
- 点"打开活动监视器"能看到具体是哪个软件在占

### 排窗口小抄（系统自带，MacKit 只是写在菜单里提醒你）

- 拖窗口到屏幕左右边缘 = 半屏，拖到四个角 = 四分之一屏
- 快捷键（🌐 是键盘左下角的地球键 fn）：
  - 🌐⌃← / 🌐⌃→ / 🌐⌃↑ / 🌐⌃↓：放到左 / 右 / 上 / 下半屏
  - 🌐⌃F：铺满；🌐⌃C：居中；🌐⌃R：恢复原来的大小
  - 🌐⌃⇧←：当前窗口放左边、上一个用的窗口放右边
- 菜单栏"窗口 → 移动与调整大小"里也都有

- 真的开了防休眠以后屏幕不黑；菜单栏的咖啡杯
- 录屏时菜单里写着"录屏中，自动防休眠"

## 怎么验收

1. 菜单 → 防休眠 → 1 小时：扳手变成咖啡杯，菜单里写着还剩多少分钟
2. 放着不动，超过你平时屏幕变黑的时间：屏幕不黑（我也能用只读的 `pmset -g assertions` 查 MacKit 有没有挡着休眠）
3. 菜单 → 防休眠 → 关掉：扳手变回来
4. 录一段屏：录的时候菜单里写着"录屏中，自动防休眠"；录完恢复
5. 菜单 → 延时截图 → 3 秒，3 秒内点开访达的"文件"菜单：倒数完屏幕冻住，菜单也在画面里，框选、复制和 ⌘1 一样
6. 再来一次，倒数时按 Esc：取消，什么都不截
7. 点开 MacKit 菜单看系统状态；开着菜单下载一个文件：网速的数字在变；点"打开活动监视器"能打开

## 技术要点（备忘）

- 防休眠：用系统的电源"断言"（和自带的 caffeinate 命令同一个办法），不要任何权限；MacKit 退出就自动失效，不会留下开关
- 菜单栏图标：防休眠时换成咖啡杯；录屏时还是红点优先
- 延时截图：倒数完先收起倒数窗口、等一下再冻屏，免得倒数的数字被截进去；倒数期间临时把 Esc 注册成全局快捷键（和长截图一样），结束就还回去
- CPU：隔一秒取两次系统的 CPU 计数，算使用率；内存：和活动监视器的"已使用内存"同一个算法；网速：读网卡收发的字节数，每秒相减（不算本机内部的回环）；磁盘：和访达显示的"可用"一致；电池：系统的电源信息
- 菜单开着时也要每秒刷新：定时器要放进菜单打开时用的那种运行模式里
- 数字格式化（字节 → KB/MB/GB、百分比、剩余时间）单独写、写单元测试
- 自检：不真的开防休眠给系统（只检查开关、计时、到点自动关的逻辑）；读一次 CPU、内存、网速、磁盘，看数字在合理范围
