原来的选项留档：

1. 更新说明怎么写
   - A. 按"截图 / 贴图 / 剪贴板 / 识别 / 录屏 / 设置"分组，每组挑两三样最有用的写成人话；最后一段写"从 1.0 升级"：设置和历史都在，屏幕录制、辅助功能要重新给一次（建议）：看的人一眼知道值不值得装

   - B. 什么都不弹，靠更新说明

## 怎么验收

1. README 和三张新图：我先在本地给你看；提交推送后在 GitHub 网页上再看一眼
2. 更新说明草稿：我写好列给你审
3. 你这台装 2.0.0：⌘1–⌘6 照旧，剪贴板历史、收藏、设置都在；第一次打开弹一次"MacKit 2.0 装好了"的提示条，再开就不弹
4. 在另一台 Mac 或朋友的电脑上试装：下载 dmg → 拖进"应用程序"→"仍要打开"→ 欢迎窗口 → 开权限 → 截一张图、打开"设置…"、勾一下开机启动
5. 发布：和 1.0 一样，我在浏览器里打开 GitHub 的新建发布页，填好标签 v2.0.0、标题、说明；**安装包你自己从访达拖进去**（上次我拖的没传上）；最后的"发布"按钮你自己点
6. 发布后：我用 GitHub 公开的接口（不用登录）核对附件的大小和 SHA-256 和本地的一样；你在你这台点"检查更新"，写着"已是最新版本 2.0.0"

## 技术要点（备忘）

- 版本号 2.0.0（build 22），标签 v2.0.0；CHANGELOG 的"未发布"改成"2.0.0（日期）"
- 安装包：scripts/release.sh → build/release/MacKit-2.0.0.dmg + .sha256；发布说明放 build/发布说明-2.0.0.md（release.sh 会清空 build/release）
- 老用户提示：设置里记"上次打开的是哪个版本"；以前打开过（欢迎窗口办过）、又是第一次见 2.x 才弹；新用户走欢迎窗口不弹；提示条用现有的带按钮提示条，链接是 GitHub 上 v2.0.0 的发布页。自检：老用户弹一次、再开不弹、新用户不弹，自检本身不弹出来
- README 的图用 MacKit 自己的画图命令：--style-preview … readme、--welcome-preview、--settings-preview（台阶 17 加的）
- README 补：能干什么（第二版的新东西）、权限表里辅助功能加上连续粘贴、常见问题"更新后截图不行了"补上辅助功能
- 发布前照旧查：安装包、README、更新说明里没有团队编号、证书名字、邮箱
- 发布后核对用 GitHub 公开接口读 v2.0.0 那一版的附件，不需要登录、不发任何东西
