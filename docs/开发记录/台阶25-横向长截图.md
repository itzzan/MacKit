# 台阶 25：横向长截图（往右滚也能拼）— 任务单（已拍板，11-06 验收通过）

> 参考：CleanShot X、Shottr 的滚动截图。

## 现在的样子

- ⌘1 框选好一块，点工具栏上的"长截图"（菜单里也有）：你往下滚，MacKit 一边看一边拼；也能点"自动滚动"（台阶 8）
- 只认往下滚：很宽的表格（Numbers、Excel、网页上的表格）、横着排的看板、时间轴，往右滚出来的东西拼不上，只能一屏一屏截了自己拼

## 做完后你能干什么

- 开始的办法不变：⌘1 框选 → "长截图"
- 框好以后**往右滚**（触控板两指往左划，或者按住 ⇧ 滚鼠标滚轮），MacKit 就横着拼；往下滚还是和以前一样竖着拼（第 1 条拍板）
- 横着拼的时候：
  - 预览条换到框的上面，横着放，最新拼上的那一截在右边
  - 控制条上写"已拼约 3.2 屏　6200 像素宽"
  - 点"自动滚动"：MacKit 替你往右滚，到头自动停（第 2 条拍板）
  - 表格冻住的第一列、左边固定的菜单栏这些不跟着滚的，只留一份（和竖着拼时网页顶上的导航栏一样）
  - 中途往回（往左）滚没关系，滚回来接着拼
  - 最宽 3 万像素（大约 13 屏），到了自动停
- 拼完和以前一样：回车或"完成"复制并存成 PNG；提示条上"标注"打开的标注窗口能左右滚
- 一次只拼一个方向（第 3 条拍板）：横着拼开始以后再上下滚，控制条提示"横着拼的时候别上下滚"

## 这一阶不做

| 功能 | 放到哪 |
|---|---|
| 横竖一起拼成一大块（像拼地图） | 不做（第 3 条拍板：一次只拼一个方向） |
| 往左、往上滚出来的内容（从右往左排的页面） | 不做：先往右、往下滚 |
| 整个网页一键截完（不用滚） | 不做：只有浏览器自己能做到（台阶 8 说过） |

## 已拍板（11-06，都按建议）

- 自动认方向：第一下往下滚就竖着拼，往右滚就横着拼
- 横着拼的自动滚动跟着方向走；一下都没滚就直接点，还是往下滚
- 一次只拼一个方向

原来的选项留档：

1. 怎么知道你要横着拼
   - A. 自动认：看你第一下往哪滚，往下就竖着拼，往右就横着拼（建议）：不用多点一下，和现在的用法一样
   - B. 开始前在控制条上选"竖着 / 横着"：不会认错，但每次要多点一下

2. 横着拼的自动滚动
   - A. 跟着方向走：你先往右滚了一下再点"自动滚动"，它就往右滚；一下都没滚就直接点，还是往下滚（和现在一样）（建议）
   - B. 横着拼不做自动滚动，只能自己滚：简单，但很宽的表格要滚很久

3. 一次能不能横竖都拼
   - A. 一次只拼一个方向（建议）：表格、看板、时间轴都是一个方向滚；认错的情况少
   - B. 横竖都拼，拼成一大块：能截地图、大画布，但难很多，滚的路线乱了就拼不好

## 怎么验收

1. 打开一个很宽的表格（Numbers、Excel，或者网页上横着能滚的表格），⌘1 框住表格 → "长截图"，往右滚到头：预览条在框上面、横着长；回车完成，打开图片看拼得对不对
2. 表格有冻住的第一列（或者左边有固定的菜单）：长图里它只出现一次
3. 再来一次，先往右滚一下，点"自动滚动"：它自己往右滚，到头停；动一下鼠标就停
4. 竖着拼照旧：网页正文往下滚、自动滚动，和以前一样
5. 拼好的横长图，提示条上点"标注"：标注窗口能左右滚，标完另存一张

## 技术要点（备忘）

- 拼接还是那一套：把拍到的每一张画面"转 90 度"（每一列变成一行），交给现在的竖着拼的算法，拼好再转回来。所以找滚了多少、绕开固定的部分（冻住的列、侧边栏）、往回滚、上限，全都现成；转画面的那一步单独写、有单元测试
- 自动认方向：还没认出来之前，每张画面竖着、横着各比一次（只在开头几张多花一点时间）；哪边先接上新内容就定成哪边，另一边不再比
- 自动滚动：横着用滚轮的左右那一路；方向反了自动换过来、记住下次用（和竖着一样）
- 预览条：横着拼时放在框的上面（上面放不下就放到控制条下面），高约 90 点；画法和竖着的一样，只是转过来
- 控制条一开始写"往下或往右滚动，MacKit 边看边拼"
- 标注窗口：本来就能左右滚，横长图打开时停在最左边
- 自检（不显示、不真的拍屏幕、不真的滚）：转画面再转回来不变；造一张很宽的假表格（左边一列冻住）横着一截一截喂进去，拼出来和原图一样、冻住的列只有一份；往回滚接得上；先竖着接上了就不认横着、先横着接上了就不认竖着；横着拼时再上下滚给提示；自动滚动发的是左右那一路（只看要发什么，不真发）；预览条摆在框上面、靠上边放不下时的位置；进度文字"像素宽"；标注窗口打开横长图停在最左边
- 实录检查 smoke-longshot 照旧（只拍不滚）
- 版本号 2.7.0（只装你这台；做完这一阶再发布 3.0）
