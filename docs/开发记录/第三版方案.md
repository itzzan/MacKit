## 一、第三版想做到什么

一句话：**标注改起来更灵活、录教程讲东西更好看、更新 MacKit 不再丢权限。**

第二版把"常用的那几样"用顺了；第三版补上用着用着会觉得"要是能……就好了"的地方。

## 五、技术上要先知道的（备忘）

- 多选、复制、上下层：标注现在是一张有先后顺序的表（AnnotationDocument），"选中一个"改成"选中一组"；上下层就是改它在表里的位置；拖一次、复制一次都算一步撤销
- 截完还能调范围：标注记的是截图框里的位置，框变了标注要跟着换算；导出时按新框裁
- 长截图标注：长图可能有几万像素高，标注窗口要能上下滚；复用贴图上标注那一套
- 自动推近：录的时候把鼠标位置和点击时间另存一份（只在你电脑上）；预览里按这些算出"什么时候推近哪里"，导出时用系统的视频合成一帧帧裁剪放大，原视频不动；要做平滑，不然画面会晃
- 屏幕打字：屏幕画笔是"不激活"的浮动窗口，打中文要输入法能接上（台阶 3 的拼音坑要再验一遍）
- 放大镜：鼠标附近一块用录屏的接口实时拍下来放大显示（已经有屏幕录制权限），不录进视频
- 粘贴改格式：只改这一次贴出去的，历史里的原文不动
- 测量间距：在测量现在"自动找边"的基础上，加一个"量到鼠标指着的那个东西"
- 签名证书：证书只用在发布版（scripts/release.sh），你自己装的还是你的开发证书；发布前照旧查包里没有你的名字、邮箱、团队编号
