|---|---|---|
| 开源协议 | 仓库里没有 | 没写协议，法律上别人不能用你的代码（看第 3 条拍板） |

## 做完后你能干什么

- GitHub 仓库的"Releases"页面出现 **MacKit 1.0.0**，带一个安装包 MacKit-1.0.0.dmg 和中文的更新说明
- 别人下载后：双击 dmg → 把 MacKit 拖进"应用程序" → 第一次打开按说明在系统设置里点一下"仍要打开"（看第 1 条拍板）
- 第一次打开出现一个**欢迎窗口**：
  - MacKit 是什么、住在菜单栏哪里
  - 要开哪些权限、为什么：屏幕录制（截图、录屏必须）；辅助功能（自动粘贴、长截图自动滚动，可选）；麦克风和摄像头（录屏时开了才要）；每个后面一个"去打开"按钮
  - 快捷键用哪一套（看第 2 条拍板），以后在菜单里也能改
  - 以后想再看：菜单"关于 MacKit → 使用说明"
- 仓库首页的说明（README）改成写给使用的人看：能干什么、怎么装、快捷键一览、要开的权限、常见问题（打不开怎么办、截图没反应、和 Snipaste 抢快捷键）、隐私说明；编译的说明挪到后面"开发"一节
- 菜单"关于 MacKit"里多两项：打开项目主页、看看有没有新版本（打开 GitHub 的发布页）
- 仓库里加上开源协议文件（LICENSE）
- 菜单和界面里写给你一个人的话，改成写给所有人的说法
- 你自己这台 Mac 不受影响：照样用 scripts/install.sh 装你自己签名的版本，⌘1–⌘6 照旧，权限不用重开

## 已拍板（11-05，都按建议）

- 安装包用临时签名（不带你的名字）
- 新用户在欢迎窗口里选快捷键，默认 ⌃⇧1–⌃⇧6；你这台照旧 ⌘1–⌘6
- 开源协议用 MIT
- 开发记录挪进 docs/开发记录/，删掉电脑型号、系统版本这类个人信息

原来的选项留档：

1. 安装包怎么签名
   - A. 免费：不用你的证书，用"临时签名"（建议先这样）。签名里没有你的名字；别人第一次打开要去"系统设置 → 隐私与安全性"点"仍要打开"；以后每次更新，别人要重新给一次屏幕录制权限（README 里写清楚怎么做）
   - B. 免费、多一步：专门为 MacKit 做一个自签名证书（需要你在"钥匙串访问"里自己点几下）。别人第一次打开还是要点"仍要打开"，但以后更新不用重新给权限
   - C. 每年 99 美元加入苹果开发者计划：签名 + 苹果公证，别人下载后双击就能开，更新也不丢权限；签名里会显示你的开发者名字（公开可见）

2. 新用户用哪套快捷键
   - A. 欢迎窗口里让他选，默认选很少跟别的软件抢的 ⌃⇧1–⌃⇧6（建议）；另一套是 ⌘1–⌘6（跟 Snipaste 的常用设置一样，但会占掉浏览器切标签）。你这台照旧用 ⌘1–⌘6
   - B. 不管，新用户也直接用 ⌘1–⌘6

3. 开源协议
   - A. MIT（建议）：最宽松，别人随便用、改、发，只要保留你的署名
   - B. GPL-3.0：别人改了再发布，也必须开源
   - C. Apache-2.0：和 MIT 差不多宽松，多了专利方面的条款

4. docs 里的开发记录
   - A. 留着当"开发过程"给人看，挪进 docs/开发记录/，删掉你的电脑型号、系统版本这类个人信息（建议）
   - B. 原样留着

注意：仓库已经公开过，以前的提交记录里这些内容还在。要彻底抹掉得改写历史，风险大，不建议；这些信息本身也不算敏感。

## 怎么验收

1. 看欢迎窗口和 README：我做好后，在你这台上用一个专门的预览命令把欢迎窗口打开给你看（不改你的设置）；README 在 GitHub 网页上看着顺眼
2. 安装包：最好在另一台 Mac 上（或者朋友的电脑）试：下载 dmg → 拖进应用程序 → 按 README 打开 → 欢迎窗口 → 开权限 → ⌃⇧1 截一张图。在你这台上试的话，会把系统记的录屏权限换成发布版的，之后你自己的版本要重新授权，所以不建议
3. 你这台：照旧 ⌘1–⌘6，什么都没变
4. 发布：我把安装包和更新说明准备好、列给你审；你点头后，我在你的 Chrome 里打开 GitHub 的新建发布页面填好，最后的"发布"按钮你自己点

## 技术要点（备忘）

- 版本号 1.0.0；新加 scripts/release.sh：编译发布版 → 签名（按第 1 条拍板）→ 做 dmg（里面放 MacKit 和"应用程序"的快捷方式）→ 算校验码（SHA-256，写进更新说明，别人能核对下载的包没被改过）
- 快捷键：现在设置里存的是"选了第几个"，直接换默认会把你的设置弄乱。改成：第一次打开 1.0 时，如果是老用户（你），把你现在用的快捷键原样写死；新用户才用欢迎窗口里选的那一套
- 欢迎窗口：普通窗口，跟着系统浅色/深色走，用统一样子；只在第一次打开时出现
- 发布版的签名里不带你的名字（选 A、B 时）；发布前检查：dmg 里没有你的团队编号、证书名字、邮箱
- 你自己的 scripts/install.sh 不变，还是你的开发证书签名
- 自检加上：老用户升级后快捷键不变、新用户默认快捷键、欢迎窗口只出现一次、关于菜单里的链接对
