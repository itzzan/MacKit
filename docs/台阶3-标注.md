# 台阶 3：标注 — 任务单（待你审）

> 2026-11-04 写。你审过、拍板后我再写代码。

## 做完后你能干什么

- 按 ⌘1 框选完松手，框不会马上消失，而是停在屏幕上，旁边出现一排工具栏（和 Snipaste 一样）
- 画之前可以先调整框：拖 8 个小方块改大小，拖框里面挪位置，方向键一次挪 1 个点
- 在框里直接画：

| 工具 | 用来干什么 | 快捷键 |
|---|---|---|
| 矩形 | 圈出重点 | R |
| 椭圆 | 圈出重点 | E |
| 箭头 | 指向某处 | A |
| 画笔 | 随手画 | P |
| 荧光笔 | 半透明的粗笔，像拿记号笔划重点 | H |
| 马赛克 | 框一块打码，盖住密码、手机号 | M |
| 文字 | 点一下就能打字，中文输入法照常用 | T |
| 序号 | 点一下放一个带数字的圆圈，1、2、3 自动往上加 | N |

- 每种工具都能选颜色（红、橙、黄、绿、蓝、黑、白，默认红色）和粗细（细、中、粗）
- 画错了：⌘Z 撤销，⇧⌘Z 重做
- 画完后，工具栏最右边几个按钮决定去哪：

| 按钮 | 做什么 | 快捷键 |
|---|---|---|
| ✓ 完成 | 复制到剪贴板，同时存文件（和现在一样） | 回车，或在框里双击 |
| 📌 贴图 | 不复制，直接钉在原位置（台阶 2 说好的"框选完直接贴"） | ⌘2 |
| 💾 另存为 | 自己选位置和文件名 | ⌘S |
| ✕ 取消 | 什么都不留 | Esc |

- 截出来的图是 Retina 原始清晰度，标注也是

## 需要你拍板

1. 松手后的流程
   - A. 松手先出工具栏（建议）：和 Snipaste 一样。不想标注时直接按回车，就和现在一样复制加保存，只多按一下
   - B. 保持现在"松手就复制"：要标注时松手前按住 ⌥
   - 不管选哪个，菜单里都留一个"快速模式"开关，随时能切到另一种

2. 贴图上的标注
   - 放到第二批（建议）：这一阶先把截图标注做扎实
   - 这一阶一起做：工作量多三成左右

## 怎么验收

1. ⌘1 框选一块，松手后看到工具栏；拖角上的小方块改大小，拖框里面挪位置
2. 八种工具各画一下，换个颜色、换个粗细
3. 文字工具里用中文输入法打一句话
4. 连按 ⌘Z 撤销到底，再 ⇧⌘Z 全部恢复
5. 回车：到微信里 ⌘V，标注都在，图很清楚
6. 再截一次，点 📌：图带着标注钉在原位置
7. 再截一次，按 Esc：什么都没留下，剪贴板也没变
8. 打开菜单切到"快速模式"，松手直接复制，和台阶 1 一样

## 技术要点（备忘）

- 新积木 MacKit/Tools/Annotate/：标注画板，只管"一张图 + 一堆标注"，截图和以后的贴图标注都用它
- 标注存成一条条记录（类型、颜色、粗细、坐标），撤销和重做就是在两个列表之间挪；画面和最终导出用同一套画法，保证看到的就是导出的
- 导出时按像素画：截图是 2 倍图，标注也按 2 倍画，线条不发虚
- 马赛克取的是冻住的原画面，不会把别的标注一起打码
- 文字用系统的文本框，中文输入法、⌘V 粘贴都能用；打完变成一条文字标注
- 选区改大小的计算单独放，写单元测试；自检用假图片画上各种标注，导出后检查像素颜色和位置对不对
