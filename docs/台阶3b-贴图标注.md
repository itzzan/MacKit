# 台阶 3 第二批：贴图上的标注 — 任务单

> 2026-11-04 写，当天你审过：两条都按推荐（Esc 放弃这次画的；画完以后还能再改）。

## 做完后你能干什么

- 对着一张贴图，右键选"标注"，或者点一下贴图再按空格（Snipaste 的习惯），就能直接在贴图上画
- 贴图下方会挂出和截图时一样的工具栏：矩形、椭圆、箭头、画笔、荧光笔、马赛克、文字、序号，颜色、粗细，撤销、重做
- 贴图放大或缩小过也能标，画上去的位置跟着图走；恢复原始大小后标注还在原处
- 马赛克糊的是这张贴图本身的画面
- 画完按回车或点 ✓：标注留在贴图上，回到普通贴图（又能拖、能缩放）
- 之后右键复制、另存为、⌘C，拿到的都是带标注的图
- 文字卡片（复制文字后贴出来的那种）也能标
- 标注时贴图不能拖动和缩放，免得一拖就画歪；退出标注后恢复

## 已拍板（2026-11-04）

1. 标注中按 Esc 或点 ✕：放弃这一次画的，贴图回到进标注之前的样子
2. 标注完以后还能再改：下次再进标注，之前画的都还在，能撤销，文字能点着改

## 怎么验收

1. ⌘1 截一块，⌘2 贴出来；右键选"标注"，下方出现工具栏
2. 画个箭头、打一句中文、放两个序号、打一块马赛克，按回车
3. 拖动、缩放这张贴图，标注跟着图走
4. 右键复制，到微信里 ⌘V：标注都在，图很清楚
5. 点一下贴图按空格，再进标注：之前画的都在，⌘Z 能撤销
6. 画几笔后按 Esc：这几笔没了，之前的还在
7. 把贴图放大到 200% 再标注，恢复原始大小后标注位置不变
8. 复制一段文字 ⌘2 贴成卡片，在卡片上画个框

## 技术要点（备忘）

- 贴图改成记"原图 + 一串标注"，显示、复制、另存时现场合成；所以能反复改（拍板第 2 条）
- 标注时在贴图里放一个和原图同样大小的画板，按贴图当前的缩放比例显示；鼠标位置自动换算回原图坐标，所以缩放过的贴图也能标
- 工具栏放进挂在贴图下方的小窗口：贴图可能比工具栏还窄；工具栏跟着贴图走，下面放不下就放上面
- 复用台阶 3 的标注编辑器，只小改一处：工具栏放哪交给使用方决定（截图放在冻住的画面里，贴图放在小窗口里）
- 标注时让 MacKit 成为当前软件，保证中文输入法能用；退出标注后把焦点还回去
- 自检：用假图片造一张贴图，喂鼠标键盘事件走一遍进标注、画、回车、Esc 放弃、再进标注撤销；放大 2 倍后画，检查合成图里标注的像素位置
